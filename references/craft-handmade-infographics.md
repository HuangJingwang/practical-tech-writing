# Baoyu 架构与结构说明图：craft-handmade

本文件是 `baoyu-infographic` 在写作流程中的配置，覆盖架构、流程、时序、状态、关系、层级与演进图。适用范围、开始生成的条件及共同交付规则统一见 [文章配图指南](article-visuals.md)。

使用完整的 [本地 baoyu-infographic skill](../../baoyu-infographic/SKILL.md)，并读取其中适用的 layout 与 [craft-handmade 风格](../../baoyu-infographic/references/styles/craft-handmade.md)。本配置补充用户已认可的画风和密度，不以一个提示词配方代替该 skill。上游来源为 [JimLiu/baoyu-skills](https://github.com/JimLiu/baoyu-skills/tree/main/skills/baoyu-infographic)，保留 MIT [许可与署名](../assets/infographics/baoyu-skills-LICENSE.txt)。

默认选项：`style: craft-handmade`，语言沿用文章，后端使用内置 `imagegen`，布局和画幅按当前结构决定。用户已确认角色、画风或请求实际出图时，沿用已有授权与偏好；不要把上游的首次设置或组合推荐变成重复确认。忠实保留事实和关系，长句可以压成准确短标签，不因上游的“保留原文”要求把正文全部塞进图中。

首次采用这套画风时查看样图。它只校准视觉语言；RAG 内容、六个阶段和折返布局都是该图的具体选择。提供给生图工具作参考时说明“借用画风，新图内容与构图按本次要求”，避免把样图的文字、关系带入新图。

## 画面语言

- 暖奶油纸张背景，如 `#FFF8F0` 或 `#F5F0E6`，纸纹很淡。
- 柔和蓝、鼠尾草绿、杏橙等两三种低饱和色，配深炭灰轮廓和清楚的手写感文字。
- 线条略有不规则，纸片可轻微参差；拼贴只用浅纸影，少量胶带或撕纸点缀。
- 留白充足，文字少而短。成人技术文章的解释图不默认加入角色或吉祥物。
- 避免照片质感、厚重纹理、复杂立体效果和铺满画面的装饰。

## 用结构表达机制

| 要表达的关系 | 画面要素 |
| --- | --- |
| 方案演进 | 节点表达新能力，连接处短语表达前一方案留下的问题；按讨论顺序排列时不要伪装成严格时间线 |
| 实体与社区 | 实际节点、边、分组区域；有社区摘要时画出与对应区域的联系 |
| 树形层级 | 父子节点和可见分叉，不能只用横排卡片替代层级 |
| 处理流程 | 输入、关键动作、输出，以及清楚的流向 |
| 分层结构 | 各层处理对象、连接和汇合位置；区分抽象层次与处理粒度，不凭层数虚构独立数据集 |
| 文件和变更 | 区分内容组织、文件链接与版本历史，分支图不能暗示自动解决语义冲突 |

数量由当前问题决定，少量主要单元通常更清楚。网络图允许有必要的边交叉，但不能压字或让连接归属不清；没有方向的关系使用普通边。结构、正文和事实依据核对后再生图。

## 构图与提示词

按关系选择布局：短流程可横向，长演进可折返，树与网络采用自身结构；短横图可用 16:9，折返概览可用 4:3，不固定沿用样图比例。

按 Baoyu 的结构化内容流程确定元素，生成前将完整提示词保存到本图资产目录的 `prompts/` 下，写清楚：

1. 图片要回答的问题、文章读者与画幅。
2. 阅读顺序、节点位置、真实连线、分组和必须保留的关系。
3. 必须出现的准确标题、标签及必要的箭头说明，语言沿用用户和文章。
4. 上述画面语言和参考图的作用，以及要避免的错误暗示。
5. 少量短标签与留白要求，详细解释留在正文。

样图提示词用来参考描述方式，不能只替换名词。区分事实依据和画风依据；未实际查看别人的图时，不声称借用了它的构图。

## 生成与修订

按 Baoyu 的后端规则读取当前环境的 `imagegen` skill，使用原生生图工具输出栅格图片。真实架构同样先核对结构，再生成和检查；不能因其需要准确文字与箭头，就自行用 SVG、HTML 或程序化手绘替代用户指定的 Baoyu 路线。

除共同配图检查外，重点查看生成模型是否写错中文、增删节点、颠倒箭头、错误合并社区或树形分支。出现这些问题时，修订提示词并重新生成，或用生图工具编辑；不使用代码覆盖文字来掩盖错误。

保存原始生成图及完整提示词，保留修订版本。交付时使用真实输出尺寸，不把提示词中要求的尺寸当成已实现尺寸。
